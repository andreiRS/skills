Print a status brief to the chat. Write nothing. This is a checkpoint, not an ending — end on the next step and go straight back to work if the user was mid-task.

Read the conversation. Reach for a tool only if the answer isn't there.

## Sections

**Goal** — one line, the main thread. Side-quests get a clause, not a block.

**Why** — two lines: what triggered this, then the deeper reason. Label it `(inferred)` if the user never said it.

**Done** — what actually landed. Not what was discussed.

**In flight** — what is half-finished and its exact state: the file being edited, the test that's red, the open question. This section earns the skill.

**Blocked** — what's stuck and on what. Drop the section when nothing is.

**Next** — one concrete step. Name a skill if one fits.

## Rules

- Half a screen. This gets called often, so keep it cheap to read.
- Agreed but never written goes in **In flight** or **Next**, never **Done**.
- Say when a thread was dropped or replaced instead of quietly leaving it out.
- Thin session: skip the sections, give two or three honest lines.
- No follow-up skills beyond the Next line. No closing summary.
